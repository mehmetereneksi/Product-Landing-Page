# Product Landing Page 🎺

A fully responsive, well-structured product landing page built for a fictional brass instrument company ("Original Trombones"). This project was created using pure HTML and CSS, showcasing modern layout techniques like CSS Grid and Flexbox, along with a mobile-first approach.

## ✨ Features

- **Sticky Navigation Bar:** The header stays at the top of the viewport while scrolling down the page.
- **Responsive Layout:** Adapts seamlessly to desktop, tablet, and mobile screens using CSS Media Queries (`@media (max-width: 768px)`).
- **Modern CSS Layouts:** Utilizes both **CSS Flexbox** (for navigation and general alignment) and **CSS Grid** (for the features section and pricing cards).
- **Embedded Media:** Includes an integrated YouTube video iframe to demonstrate the product.
- **Interactive Form:** A clean email subscription form that visually responds to user input and submits to a mock endpoint.
- **Custom Icons:** Uses Font Awesome library to enhance the UI with high-quality icons.

## 🛠️ Technologies Used

- **HTML5:** Semantic structuring, embedded media (`<iframe>`), and forms.
- **CSS3:** Advanced styling, CSS Grid, Flexbox, smooth transitions, and responsive media queries.
- **Font Awesome:** External library for UI icons.
